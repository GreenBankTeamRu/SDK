Первоначальная настройка проекта для работы
======

## Структура проекта

```
.
├── asciidoc #папка содержит документацию в формате *.adoc, которая впоследствии попадает в https://dev-sbbol.delta.sbrf.ru/docs
├── docker #папка содержит файлы для сборки образа докера вашего приложения(по умолчанию это файл запуска вашего приложения - entrypoint.sh)
│   └── Dockerfile #файл, по которому будет сделан Docker образ вашего приложения
├── gradle #папка содержит файлы для gradle
│   └── dependency-locks #папка, содержащая lockfile с зависимостями приложения
│   └── wrapper #папка с враппером gradle
├── helm #папка содержит helm чарты, используемые для деплоя в DropApp
├── jenkins #папка содержит ваши кастомные pipelines для Jenkins, настройки для централизованных pipelines и ресурсы для них
│   └── resources #папка, содержащая ресурсы, используемые на ПР-чеке
│   └── settings.yml #файл с настройками для централизованных pipelines
├── openapi #папка содержит файлы openapi для публикации в META
├── src #папка содержит исходный код, ресурсы и тесты вашего приложения
└── sowa #папка содержит шаблонизированные конфиги Sowa для вашего приложения(опциональная директория)
```

## Правка jenkins/settings.yml

### credentials

Актуализировать данный раздел согласно [документации](https://dev-sbbol.delta.sbrf.ru/docs/devops-pipelines/master/#jenkins_credentials)

### release

* artifact_id - artifact id репозитория в nexus;
* group_id - group id репозитория в nexus;
* image_name - имя докер образа;
* doc_path - путь до папки с документацией.

## Правка gradle.properties

* artifactId - должен содержать название артефакта nexus для release.
* groupId - должен содержать название группы nexus для release.
* repo - должен содержать URL на nexus repo с сборкой.

## Настройка сборка тестового покрытия

Во всех местах отмеченных комментарием начинающимся с `FIXME COVERAGE:`, необходимо внести соответствующие изменения.

  по [инструкции](https://confluence.sberbank.ru/pages/viewpage.action?pageId=134512581) заполнить поля, для
