Документация по интеграции с API Сбербанка

Подготовка

SDK работает на версии Java 1.8 и выше.

Подключение зависимостей

Для работы с API Сбербанка необходимо подключить соответствующие зависимости в вашем проекте. В зависимости от используемого инструмента сборки (Gradle или Maven), добавьте соответствующие блоки в конфигурационные файлы.

Для Gradle:

В блоке repositories указывается путь к локальной директории, где хранятся JAR-файлы SDK. В блоке dependencies подключаются необходимые библиотеки для работы с моментальными платежами и H2H.

groovy 
repositories {
    flatDir {
        dirs("/Users/User/Documents/SDK/") // Укажите путь к директории, где находятся JAR-файлы SDK
    }
}

dependencies {
    implementation("ru.sberbank.sbbol.sberbusinessapi:sdk-instantpayment:release-1.0.0-SNAPSHOT") // Подключение SDK для работы с моментальными платежами
    implementation("ru.sberbank.sbbol.sberbusinessapi:sdk-h2h:release-1.0.0-SNAPSHOT") // Подключение SDK для работы с H2H (Host-to-Host)
}

Для Maven:

В блоке указывается путь к локальной директории с JAR-файлами. В блоке подключаются библиотеки для работы с моментальными платежами и H2H.

xml 

    
        local-sdk-repo

Добавление банковского сертификата в JDK

Для работы с API и установкой TLS соединения необходимо добавить банковский сертификат. Это обеспечивает безопасное соединение с серверами Сбербанка.

Есть 2 варианта:

  1. Добавить сертификат в хранилище сертификатов JDK.
    Команда keytool добавляет сертификат в хранилище JDK, что позволяет приложению использовать его для безопасного взаимодействия с серверами Сбербанка.
    Найдите директорию, где находится файл cacerts. Например, для JDK 17 путь может быть следующим:
    /Library/Java/JavaVirtualMachines/temurin-17.jdk/Contents/Home/lib/security
    Используйте команду keytool для добавления сертификата: 
    keytool -importcert -alias <алиас> -file <путь_к_файлу_сертификата> -keystore <путь_к_файлу_cacerts> -storepass changeit
    • <алиас> — произвольное имя для сертификата
    • <путь_к_файлу_сертификата> — путь к файлу сертификата
    • <путь_к_файлу_cacerts> — путь к файлу cacerts
  2. Передавать путь к сертификату при настройке HttpClientFactory

Модуль авторизации (Общий, входит в зависимость для SDK для моментальных платежей и SDK для H2H)

Подготовка

Для работы с модулем авторизации необходимо создать экземпляр httpClient и экземпляр API сервиса. Это позволяет выполнять запросы к серверу авторизации для получения токенов доступа и других операций.

Экземпляр API клиента настраивается с указанием хоста сервера авторизации, таймаута подключения, пути к сертификату и пароля. Логирование можно включить для отладки.

java 
HttpClientFactory httpClientFactory = HttpClientFactory.of()
        .host("https://iftfintech.testsbi.sberbank.ru:9443/ic/sso/api/oauth/token") // Укажите хост сервера авторизации
        .connectTimeout(60000) // Таймаут подключения (не обязательно)
        .customCertPath("/Users/User/Documents/certs/SBBAPI_1958729756739688672_173a5fe4-68f5-4014-91c7-1730e19e3324.p12") // Путь к сертификату полученному в ЛК
        // Путь к доверенному сертификату (Для тестового стенда - сертификат МинЦифр), необязательный, если сертификат лежит в хранилище сертификатов JDK
        .customTrustPath("/Users/User/Documents/certs/минЦифры/russiantrustedca.pem")
        .customCertPassword("Yjubherb123") // Пароль к сертификату
        .isEnableLogs(false) // Включение логов для тестирования (не обязательно)
        .build();
java 
AuthorizationApiClient api = new AuthorizationApiClientImpl(httpClientFactory);

Получение токена доступа

Токен доступа необходим для выполнения запросов к API. Для его получения требуется код авторизации, идентификатор клиента, URI перенаправления и секрет клиента.

Описание метода: /oauth-token-post
Входные параметры 
TokenRequest request = TokenRequest.builder()
        .code(CODE) // Код авторизации
        .clientId(CLIENT_ID) // Идентификатор клиента
        .redirectUri("http://ya.ru") // URI перенаправления
        .clientSecret(CLIENT_SECRET) // Секрет клиента
        .build();
TokenResponse accessToken = api.getAccessToken(request, true);

Обновление токена доступа

Токен доступа имеет ограниченный срок действия. Для его обновления используется токен обновления и верификатор кода.

Описание метода: /oauth/token
Входные параметры 
TokenRequest request = TokenRequest.builder()
        .refreshToken(REFRESH_TOKEN) // Токен обновления
        .codeVerifier("cu2_PT-7bXYDwW81RysRM-ZKMgak34ntK3WpBQ8tK9_nrwBnOkphxNJV13kv_YdCQosMpgyVvfDMZBnYKYq22WCyuDDkz4ZnnzxyNs6ohaXhS4ojXY3kZacNgkNCOQhK") // Верификатор кода
        .clientId(CLIENT_ID) // Идентификатор клиента
        .redirectUri("http%3A%2F%2Fya.ru") // URI перенаправления
        .clientSecret(CLIENT_SECRET) // Секрет клиента
        .build();
TokenBodyResponse accessToken = api.getRefreshToken(request);

Изменение секрета клиента

Этот метод позволяет изменить секрет клиента, что может быть полезно для повышения безопасности.

Входные параметры 
ChangeClientSecretRequest request = ChangeClientSecretRequest.builder()
        .accessToken(ACCESS_TOKEN) // Токен доступа
        .clientId(CLIENT_ID) // Идентификатор клиента
        .clientSecret(CLIENT_SECRET) // Текущий секрет клиента
        .newClientSecret("IzpwiRQIvt332uGEyNDWlSB4KYAI5ho3") // Новый секрет клиента
        .build();
ChangeClientSecretResponse accessToken = api.getRefreshClientSecret(request);

Отзыв токена

Этот метод позволяет отозвать токен доступа или обновления, что полезно для завершения сессии.

Описание метода: /oauth/revoke
Входные параметры 
RevokeTokenRequest request = RevokeTokenRequest.builder()
        .clientId(CLIENT_ID) // Идентификатор клиента
        .clientSecret(CLIENT_SECRET) // Секрет клиента
        .token(ACCESS_TOKEN) // Токен доступа
        .tokenTypeHint(RevokeTokenRequest.TokenTypeHint.refresh_token) // Тип токена
        .build();
api.getRevokeToken(request);

Генерация PKCE кодов

PKCE (Proof Key for Code Exchange) — это механизм для повышения безопасности OAuth 2.0. Методы позволяют генерировать код верификатора и код вызова.

Документация: RFC 7636
Пример генерации кодов: PKCE Code Generator

var securityService = new SecurityServiceImpl();
String PCSEcodeChallenge = securityService.generatePKCECodeChallenge();              // Генерация code_challenge с генерацией code_verifier
String PCSEcodeChallenge = securityService.generatePKCECodeChallenge(CODE_VERIFIER); // Генерация code_challenge с использованием заранее сгенерированного code_verifier
String PCSEcodeVerify = securityService.generatePKCECodeVerifier();                  // Значение рандомно генерируется в диапазоне от 43 до 128
String PCSEcodeVerify = securityService.generatePKCECodeVerifier(46);                // Задается конкретное значение в диапазоне от 43 до 128

Этот метод позволяет создавать черновики платежных поручений с фиксированным сроком действия, в которых отсутствует возможность изменить сумму оплаты и реквизиты получателя.

PaymentInvoiceRequest paymentInvoiceRequest = PaymentInvoiceRequest.builder()
                 .amount(number) // float, сумма платежа
                 .date("string") // ISO 8601 YYYY-MM-DD, дата составления документа
                 .deliveryKind("string") // string, Вид платежа. Если не заполнено или 0, то будет присвоено значение "электронно"
                 .expirationDate("string") // ISO 8601 YYYY-MM-DD, Дата истечения заказа (платеж должен быть подтвержден клиентом)
                 .externalId("string") // UUID, Идентификатор документа
                 .operationCode("string") // string, Код операции
                 .orderNumber("string") // string, Номер заказа
                 .payeeAccount("string") // string, Счет получателя платежа
                 .paymentNumber("string") // string, Номер платежного поручения
                 .priority("string") // string, Очередность платежа
                 .purpose("string") // string, Назначение платежа
                 .urgencyCode("string") // string, Код срочности
                 .vat(Vat.builder() // vat, object, Данные НДС
                               .type("string") // Тип связанного документа (доступное значение для заполнения - exportContractInsure), с которым необходимо связать платежное поручение
                               .amount(number) // float, Сумма НДС
                               .rate("string") // string, Ставка НДС
                               .build())
                 .build();
 PaymentInvoiceResponse paymentInvoice = api.createPaymentInvoice(ACCESS_TOKEN, paymentInvoiceRequest);
